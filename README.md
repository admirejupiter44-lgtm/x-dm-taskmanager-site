# X DM Task Manager

Xのダイレクトメッセージを使った物販取引を整理するための、個人用の取引管理ツールです。

## Purpose

返信、支払い確認、発送準備、発送、完了などの進捗を取引ごとに整理し、次に必要な対応を把握しやすくすることを目的としています。

## X API usage

- 認証した自分のXアカウントに関係するDMデータを、取引管理のために取得します。
- 取得データは取引状況の整理・表示のために使用します。
- Xから取得したデータを第三者へ販売・公開・再配布することを目的としていません。
- 重要な取引ステータスの確定はユーザーが確認して行う設計です。
